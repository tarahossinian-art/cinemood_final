# پروژه بخش هوش ۳ - سینمود

این پروژه برای چالش سینمود طراحی شده و با استفاده از بینایی کامپیوتر، حال افراد (شاد، غمگین، عصبانی، متعجب، خنثی) را از روی عکس چهره تشخیص می‌دهد.

## امکانات (حداقل‌ها و امتیازهای اضافه)
- استفاده از مدل MobileNetV2 (Transfer Learning) برای آموزش ۵ حالت چهره.
- استفاده از کتابخانه **OpenCV** برای پیدا کردن و برش دادن دقیقاً کادر چهره (اجرای زنده با وبکم).
- خروجی دقیقاً مطابق فرمت JSON قرارداد مشترک مسابقه.
- رسم ماتریس درهم‌ریختگی (Confusion Matrix) و تحلیل خطاها.
- رابط کاربری وب (UI) با Gradio برای آپلود عکس یا گرفتن عکس زنده با وبکم.

## نحوه اجرا
کافیست فایل `Untitled7.ipynb` را در Google Colab باز کرده، دیتاست FER-2013 (فایل archive.zip) را آپلود کرده و سلول‌ها را به ترتیب اجرا کنید.
